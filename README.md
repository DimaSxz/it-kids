# Репозиторий с заданиями для школы программирования "IT-Kids"

Доступные задания:

* [Ханойские башни](./hanoi-practice/README.md)

Этот проект содержит небольшие учебные игры и задания для школьников: от простых браузерных механик до мини-сервиса на Node.js.

## Готовые уроки (демо, можно запускать и играть)

### 1) Ханойские башни (демо)

Папка: `hanoi/`

Ученики играют в головоломку "Ханойские башни" (клики по стержням), видят счетчик ходов и авто-решение.

Что полезного можно обсудить на уроке:

* правила и допустимость хода (перемещать можно только верхний диск на больший);
* минимальное число ходов (в основе формула `2^n - 1`);
* рекурсия как способ построить последовательность шагов (авто-режим).

### 2) Крестики-нолики (демо)

Папка: `tic-tac-toe/`

Браузерная игра `Крестики-нолики` с полем размера `3x3..5x5`.

Что полезного можно обсудить на уроке:

* представление клетки как индекса в сетке;
* проверка победы по строкам, столбцам и диагоналям;
* (по желанию) стратегия компьютера в режиме "играть с компьютером".

## Учебные заготовки (задания для выполнения учениками)

### 1) Ханойские башни (практика)

Папка: `hanoi-practice/`

Внутри описано пошаговое задание:

* реализовать стартовую логику в `server/start.js`;
* реализовать проверку и применение хода в `server/move.js`;
* (опционально) добавить API-метод для вывода количества игровых сессий.

Подробнее: `hanoi-practice/README.md`

### 2) Крестики-нолики (практика)

Папка: `tic-tac-toe-practice/`

По коду видно, что логика победы уже сделана, а для компьютера в файле `script.js` требуется дописать функцию `doComputerMove()`.

## Как запустить проект

### Ханойские башни (демо)

* Запустите сервер Node.js:

```bash
cd "hanoi/server"
node index.js
```

* В браузере откройте файл: `hanoi/client/index.html`

* Играйте. Сервер работает по адресу `http://localhost:3000`.

### Ханойские башни (практика)

* Запустите сервер Node.js:

```bash
cd "hanoi-practice/server"
node index.js
```

* Откройте в браузере: `hanoi-practice/client/index.html`

* Ученикам нужно реализовать функции в `server/start.js` и `server/move.js`, сохранять файлы и перезапускать сервер после правок (как в `hanoi-practice/README.md`).

### Крестики-нолики (демо и практика)

* Откройте в браузере:
  * демо: `tic-tac-toe/index.html`
  * практика: `tic-tac-toe-practice/index.html`

* Серверы запускать не нужно.

## Как преподавать школьникам

Ниже пример схемы урока на 45-60 минут (можно адаптировать под возраст).

1. Разогрев (5-10 минут)

   * Дайте ученикам поиграть 3-5 минут и сформулируйте правила вслух.
   * Задайте простой вопрос: "Почему некоторые ходы нельзя делать?".

2. Привязка к коду (10-15 минут)

   * Ханой: объясните, что состояние игры хранится как 3 стержня (массивы дисков), а ход — это пары `{from, to}`.
   * Крестики-нолики: объясните, что победа определяется проверкой индексов клеток на строках/столбцах/диагоналях.

3. Практика (20-30 минут)

   * Ханойские башни (практика): попросите сделать поэтапно `getDefaultState`/`startGame`, затем `applyMove`, затем (по желанию) доп. этапы.
   * Крестики-нолики (практика): задача — реализовать `doComputerMove()` (например, простой стратегией: случайный ход, затем центр, затем блок/победа).

4. Проверка и обсуждение (5-10 минут)

   * Ученики демонстрируют результат: "какой ход делает компьютер/как игра применяет ход".
   * Каждый объясняет логику 1-2 минутами: "какие условия проверяем и почему".
